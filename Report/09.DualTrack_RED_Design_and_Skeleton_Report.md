## 5. 실행·검증 결과

### 5.1 pytest (스켈레톤 최종)

```powershell
python -m pytest tests/boundary/ tests/entity/ -v
```

```text
collected 23 items
23 failed in 0.06s
passed: 0
```

모든 실패는 `Failed: RED: <Test ID> — …` (의도적 `pytest.fail`).

### 5.2 collection ERROR 이슈 (해결)

| 현상 | 원인 | 조치 |
|------|------|------|
| `ModuleNotFoundError: entity.services` | 스켈레톤 **모듈 최상단** import | import를 **주석**으로 이동, `pytest.fail`만 실행 |
| `ModuleNotFoundError: control` | `control.solve_partial_magic_square` 미존재 | 동일 |
| `--cov` 시 0건 수집 | collection 중단 | 위 조치 후 23건 수집·실패 확인 |

**참고:** GREEN 단계에서 `src/entity/services/`, `src/control/` 구현 후 주석 import를 활성화하고 assert로 전환한다.

### 5.3 커버리지 (스켈레톤 직후)

```powershell
python -m pytest tests/entity/ --cov=src --cov-report=html
```

- 스켈레톤은 Domain 로직을 호출하지 않아 **의미 있는 Domain 커버리지 기여는 0%에 가깝다.**
- Boundary 스켈레톤도 `ScreenBoundary` 실호출 없음 → RED 단계 정상.
