## 1. Executive Summary

본 스프린트는 **PyQt6 기반 데스크톱 GUI**를 추가하고, 2빈칸 마방진 퍼즐을 실제로 해결할 수 있도록 **Entity → Control → Boundary** 파이프라인을 최소 구현했다. GUI는 `ScreenBoundary.submit()`을 유일한 진입점으로 사용하며, AC-FR-01-01 입력 크기 검증(25건)은 **회귀 없이 GREEN**을 유지한다.

| 성과 | 산출물 / 상태 |
|------|----------------|
| 데스크톱 UI | `src/boundary/ui/main_window.py` — 4×4 격자·해결·초기화·샘플 |
| 진입점 | `main.py` — `python main.py` 로 실행 |
| Domain 솔버 | `src/entity/solver.py` — P-2~P-5 검증, 두 조합 시도, I-1~I-7 판정 |
| Control | `src/control/solve.py` — `resolve()` 포트 |
| Boundary 확장 | `screen_boundary.py` — 유효 4×4 시 `resolve()` 위임, `DomainError` → `FailureResult` |
| 의존성 | `requirements.txt` — `PyQt6`, `pydantic`, `pytest`, `pytest-cov` |
| AC-FR-01-01 회귀 | **25/25 PASS** |
| 솔버 검증 (G2) | `[3, 3, 6, 4, 4, 1]` — SC-DOM-SOL-001 일치 |

## 2. 배경·목적

### 2.1 요청

> PyQt를 이용해서 GUI로 실행할 수 있도록 완성

Report/10까지는 Boundary **크기 검증(AC-FR-01-01)** 만 GREEN이었고, `resolve()` 위임 경로는 `NotImplementedError`로 의도적 미구현 상태였다. 본 스프린트는 **실행 가능한 MVP**를 목표로 GUI와 Domain 솔버를 함께 도입했다.

### 2.2 설계 원칙 (ECB)

| 레이어 | 책임 | 본 스프린트 구현 |
|--------|------|------------------|
| **boundary** | 입출력·UI·계약 수준 검증 | PyQt `MainWindow`, `ScreenBoundary.submit()` |
| **control** | 유스케이스 오케스트레이션 | `resolve()` → `entity.solver.solve()` |
| **entity** | 순수 도메인 규칙 | 부분 격자 검증, 마방진 판정, 두 조합 해결 |

**의존 방향:** `boundary → control → entity` (역방향 없음)

### 3.2 Domain 솔버 (`entity/solver.py`)

| 함수 | 책임 | 보호 불변식 |
|------|------|-------------|
| `validate_partial_grid` | 빈칸 2개, 값 범위, 0 제외 중복 | P-2, P-3, P-4 |
| `locate_empty_cells` | 행 우선 1-index 좌표 | O-5 |
| `find_missing_numbers` | 누락 2수 오름차순 | O-4 |
| `is_magic_square` | 완성 격자 8선 합 34 | I-1~I-7 |
| `solve` | small-first → reverse 두 조합 시도 | O-6, O-7, SC-DOM-SOL-001 |

**도메인 오류 코드 (고정 메시지):**

| code | message |
|------|---------|
| `EMPTY_COUNT_INVALID` | 빈칸(0)은 정확히 2개여야 합니다. |
| `VALUE_RANGE_INVALID` | 0이 아닌 값은 1~16이어야 합니다. |
| `DUPLICATE_NONZERO` | 0을 제외한 값은 중복될 수 없습니다. |
| `NO_VALID_COMPLETION` | 주어진 빈칸에 유효한 마방진 완성이 없습니다. |

### 3.3 Boundary 확장 (`screen_boundary.py`)

```python
# 요약 — 유효 4×4 이후 경로 (Report/10 대비 신규)
try:
    return self._resolve(grid)
except DomainError as exc:
    return FailureResult(code=exc.code, message=exc.message)
```

- AC-FR-01-01 **INVALID_SIZE** 분기(None, `[]`, jagged, 3×4)는 **변경 없음**
- `resolve` 미호출 격리 테스트 **25건 중 해당 9건 유지 PASS**

## 5. 아키텍처 흐름

```
User (PyQt MainWindow)
    │ read grid, parse cells
    ▼
ScreenBoundary.submit(grid)
    │ INVALID_SIZE? → FailureResult (AC-FR-01-01)
    ▼
control.solve.resolve(grid)
    ▼
entity.solver.solve(grid)
    │ DomainError? → FailureResult
    ▼
list[int] length 6  →  GUI 성공 표시 + 빈칸 채움
```

**의존성 주입:** `MainWindow(boundary)` — 테스트 시 `mock_resolve` 주입 가능 (AC-FR-01-01 패턴 유지).
